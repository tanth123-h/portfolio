# Ocean motion polish

The approved design keeps all portfolio content and media intact. A CSS particle layer adds sparse drifting specks and occasional bubbles; the photo-free porthole gains moving light and gentle fine-pointer response. A curved transition and graduated teal sections reinforce the descent from surface to depth.

References: [The Deep Sea](https://neal.fun/deep-sea/) for the descent concept and [Lost Cities: World of Corals](https://bwco.info/work/lost-cities-world-of-corals/) for restrained underwater particles. No artwork, code, or audio was copied.

Motion is optional, with a persistent bilingual toggle. System reduced-motion preferences take precedence. Hidden tabs pause animation. Mobile uses 10 particles instead of 24. Decorative elements cannot intercept input and disappear behind open media dialogs. No animation framework or continuous JavaScript rendering loop was added.

Verification: 10 Node tests, syntax checks, English/Thai responsive checks at eight viewport widths, keyboard regression checks, persistent pause, and live reduced-motion changes. Mobile browser checks are desktop Chromium emulation, not physical-device performance measurements.
